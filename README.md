# Habit Tracker

A Habit Tracker application made using HTML, tailwinds, JavaScript and Node.js

## Set Up

1.  Copy `.env.example` to a new file named `,env`,
2.  Add the MongoDB connection string to ` MONGODB_URL` in the `.env` file.
3.  Add a random secret to `JWT_SECRET in the `.env` file.
4.  Run `npm install`.

## Running the application

### Development

To run the application in development mode use `npm run dev`

### Production

To run the application in the production mode use `npm start`
